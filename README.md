# Recognition Dashboard (mockup)

Clickable mockup of an IQAC dashboard that tracks accreditation, rankings,
ratings and awards across every school of the university.

- **Accreditation:** NAAC, NBA, International
- **Ranking:** NIRF, QS, THE
- **Ratings:** QS Stars, QS I-GAUGE, IIC, GreenMetric, ISO & NABL
- **Awards:** Institution, Faculty, Student

Frameworks and weights follow the IQAC Quality Recognition Handbook.
All figures are illustrative sample data.

Single static page (`index.html`), no build step. Open it in a browser or
serve the folder with any static server.
